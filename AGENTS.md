# Agent notes

This is a two-hour production triage take-home on an existing single-screen React Native app. Read `README.md` and `DECISIONS.md` before changing structure.

## Stack

Expo SDK 58, React Native 0.88, TypeScript. Entry is `index.ts` -> `App.tsx` -> `src/screens/IncidentQueueScreen.tsx`. Do not migrate to Expo Router; Jest tests mount `IncidentQueueScreen` directly.

`ios/` and `android/` are generated by Expo. Do not add them. Libraries already in the project (`@shopify/flash-list`, `react-native-reanimated`, `react-native-gesture-handler`, `@react-native-async-storage/async-storage`, `zustand`) run in Expo Go. Install anything new with `npx expo install`.

## Contracts

Keep consuming `incidentApi` (`src/services/incidentApi.ts`) and `alertFeed` (`src/services/alertFeed.ts`), keep the `testID`s listed in `README.md`, and keep `jest.setup.js` compatible with `@shopify/flash-list` and `@react-native-async-storage/async-storage`.

## Checks

```bash
npx tsc --noEmit
npm test
```

Do not weaken `__tests__/IncidentQueueSmoke.test.tsx` to make a change pass.
